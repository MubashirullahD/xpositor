# Changelog

## 0.1.0 (preview)

First public preview.

- Pair a phone from the Xpositor sidebar with a QR code, over your local Wi-Fi or a temporary HTTPS Cloudflare tunnel.
- Read changed files on the phone, mark them reviewed and keep private notes that stay on the device, even offline.
- Guided AI walkthroughs, line-by-line explanations and follow-up questions, using the Codex or Claude Code login already on your laptop. No API billing unless you choose it.
- Optional local voice (Kokoro) that reads walkthroughs aloud; nothing is sent to a cloud speech service.
